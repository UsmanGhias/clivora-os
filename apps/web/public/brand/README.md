# CLIVORA Logo Asset Guide

## Core idea

The CLIVORA mark is a geometric **C** formed by two connected paths. The upper
teal path represents clients; the lower violet path represents freelancers and
agencies. Their central meeting point represents CLIVORA as the operating
system joining both sides.

## Brand colors

| Token | Hex | Use |
| --- | --- | --- |
| Midnight Navy | `#071426` | App icon and dark brand surfaces |
| Teal | `#19D3C5` | Client/collaboration accent |
| Sky Blue | `#35B8EB` | Connection transition |
| Violet | `#7C5CFC` | Freelancer/product accent |
| Off White | `#F5F8FC` | Wordmark on dark surfaces |

## Which file to use

- `clivora-logo-on-dark.*`: website/app dark navigation and footer.
- `clivora-logo-on-light.*`: white or very light marketing pages.
- `clivora-mark.*`: icon-only use, loading screens, compact sidebars.
- `clivora-app-icon-1024.png`: Play Store source icon and general app icon.
- `clivora-pwa-192.png` and `clivora-pwa-512.png`: web app manifest.
- `clivora-android-adaptive-foreground-432.png`: Android adaptive foreground.
- `clivora-android-adaptive-background-432.png`: Android adaptive background.
- `clivora-favicon.*`: browser tab and web manifest.
- `clivora-apple-touch-icon-180.png`: iOS/Safari homescreen bookmark.
- `clivora-social-avatar-1200.png`: LinkedIn, X, Facebook, TikTok profile.
- `clivora-og-share-1200x630.png`: website social-sharing preview.
- `clivora-splash-1080x1920.png`: mobile splash artwork.

## Safe use rules

- Keep empty space around the mark equal to at least 20% of its width.
- Never stretch, rotate, add shadows, or recolor individual gradient stops.
- At widths below 120 px, use the symbol only, not the full wordmark.
- Minimum favicon size: 16×16 px. Minimum horizontal wordmark width: 160 px.
- Use the monochrome white mark only when gradients are unavailable.
